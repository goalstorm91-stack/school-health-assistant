# 보건교사 업무 비서

초등학교 보건업무를 위한 React 19 / TypeScript / Next.js 시제품입니다. 모든 학생과 방문 내역은 가상 데이터이며, 데이터는 현재 탭의 메모리에만 저장됩니다. 새로고침 시 초기화됩니다. 실제 학생정보를 입력하지 마세요.

## 실행

Node 22에서 `npm ci`, `npm run dev`를 실행합니다. 로컬 주소는 http://localhost:5173 입니다. `npm run build`로 Next.js 배포 산출물을 생성하고 `npm start`로 실행합니다.

## Vercel 배포

GitHub 저장소를 Vercel에서 가져오면 `vercel.json`에 따라 Next.js로 빌드됩니다. 루트 디렉터리는 저장소 최상위이며, 현재 데모에는 환경변수나 외부 DB가 필요하지 않습니다. GitHub의 main 브랜치를 배포 브랜치로 사용합니다.

기존 Sites 환경의 명령은 `dev:sites`, `build:sites`, `start:sites`로 보존했습니다. Vercel에서는 Sites 전용 인증 및 Cloudflare 바인딩을 사용하지 않습니다. 이 데모에 학교 인증이나 영구 저장 기능이 추가되는 것은 아닙니다.

검증: `node --experimental-strip-types --test tests/health.test.ts`, `npx tsc --noEmit`.

## 구현 범위

- 홈과 6개 업무 메뉴, 가상 학생 검색 및 동명이인 구분.
- 한 방문의 입실·관찰·복귀·귀가, 수정과 취소, 최근 이력, 입력 시각 보존.
- 방문 사용품의 묶음별 차감·차이 반영·취소 반환, 유효기간 우선 사용, 재고 부족 시 원자적 거절.
- 학생별 이력, 증상 필터, 기간·횟수·같은 증상 규칙과 근거 기록.
- 일·월·사용자 지정 학기, 학년·증상·처치 통계와 근거 조회, CSV 내보내기.
- 입고 묶음, 유효기간, 수동 입출고, 부족 재고, 변동 이력.
- 월간 일정, 오늘·이번 주·미완료 목록, 주간 반복 4회와 회차별 완료.
- 규칙 기반 운영 보고서·가정통신문·업무 요약, 편집 및 텍스트 내려받기.
- 향후 외부 AI를 위한 허용 필드/최소 집단 억제 경계와 미연결 캘린더 인터페이스.

## 데모와 운영 버전의 구분

학교 계정 인증, 서버 저장소, 권한 및 실제 감사로그, 외부 AI, Google Calendar는 연결하지 않았습니다. 데모 내 사용자 입력도 외부로 전송하지 않습니다. AI 문서는 앱 내부 코드가 작성하며, 교사가 검토해야 하는 초안입니다. 자연어 자유 질의는 이번 시제품 범위에 포함하지 않습니다.

운영 전 설계는 `docs/production-design.md`에 있습니다. 화면의 데모 표시는 실제 운영 요건을 구현했다는 의미가 아닙니다.
